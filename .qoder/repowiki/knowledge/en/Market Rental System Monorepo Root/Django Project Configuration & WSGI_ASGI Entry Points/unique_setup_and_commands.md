Local development can run zero-config against SQLite; to use the bundled XAMPP MySQL/MariaDB server set `DB_ENGINE=mysql` in `.env` (defaults: host `127.0.0.1`, port `3306`, user `root`, empty password, database `market_rental`). Production requires `DJANGO_SECRET_KEY`, `DATABASE_URL`, and `DJANGO_ALLOWED_HOSTS` env vars; static files must be collected via `collectstatic` so WhiteNoise can serve hashed filenames.
